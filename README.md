## Use Microting.EntityFrameworkCore.MySql

Pomelo.EntityFrameworkCore.MySql supports EF.Core 9.0 and earlier.
For EF.Core 10 and later, use [Microting.EntityFrameworkCore.MySql](https://github.com/microting/Pomelo.EntityFrameworkCore.MySql).

For historical documentation see [the v9.0 README](https://github.com/PomeloFoundation/Pomelo.EntityFrameworkCore.MySql/blob/9.0.0/README.md).
